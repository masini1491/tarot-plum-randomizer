# 塔羅牌＋梅花易數隨機抽取器

一個可直接在瀏覽器使用的單頁式塔羅牌與梅花易數隨機抽取工具，介面與說明以繁體中文為主，並支援桌面與手機版面。

## 線上使用

Vercel：<https://tarot-plum-randomizer-masini1491-9205.vercel.app>

## 功能

### 塔羅牌

- 使用完整 78 張塔羅牌組。
- 單題可抽 1～24 張。
- 支援正位／逆位隨機。
- 同一次抽牌不會出現重複牌。
- 支援多題連續抽牌，每題可獨立設定 1～24 張。
- 連續抽牌時，每一題都會重新洗完整牌組。
- 使用精簡牌名輸出，例如：`杯后正`、`劍七逆`、`命輪正`。

### 梅花易數

- 固定採用「雙數起卦」。
- 隨機產生兩個 `000～999` 的數字 A、B。
- `A ÷ 8` 的餘數決定上卦。
- `B ÷ 8` 的餘數決定下卦。
- `(A + B) ÷ 6` 的餘數決定動爻。
- 八卦餘數為 0 時視為坤卦；動爻餘數為 0 時視為第 6 爻。
- 顯示上卦、下卦、動爻與完整六十四卦本卦名稱，例如：`水雷屯`、`乾為天`、`火水未濟`。

### 共用功能

- 同一題可只抽塔羅、只起梅花易數，或同時取得兩種結果。
- 支援一鍵複製結果。
- 複製內容依序為：題目 → 時間 → 結果。
- 時間格式為 `YYYY/MM/DD HH:MM`。
- 支援手機版響應式排版。

## 隨機方式

- 優先使用瀏覽器的 `crypto.getRandomValues()` 產生亂數。
- 透過拒絕取樣避免簡單取模造成的偏差。
- 塔羅牌使用 Fisher–Yates 洗牌後再依指定張數取牌。
- 若瀏覽器不支援 Web Crypto，才使用 `Math.random()` 作為備援。
