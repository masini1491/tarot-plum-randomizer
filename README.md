# Tarot + Plum Randomizer

單頁式塔羅牌與梅花易數隨機抽取工具，可直接在瀏覽器使用，並支援手機版介面。

## 功能

- 單題塔羅可抽 1～24 張
- 多題連續塔羅，每題可獨立設定 1～24 張
- 每題重新洗完整 78 張牌組，單題內不重複
- 支援正位／逆位隨機
- 精簡牌名輸出，例如：`杯后正`、`劍七逆`、`命輪正`
- 梅花易數固定採雙數起卦
- 隨機產生兩個 `000～999` 數字 A、B
- A÷8 → 上卦；B÷8 → 下卦；(A+B)÷6 → 動爻
- 餘 0 分別視為坤卦／第 6 爻
- 顯示上卦、下卦、動爻與完整六十四卦卦名，例如：`水雷屯`、`乾為天`、`火水未濟`
- 同一題可同時抽塔羅＋梅花易數
- 支援一鍵複製結果
- 複製格式：題目 → 時間 → 結果
- 手機版響應式排版
